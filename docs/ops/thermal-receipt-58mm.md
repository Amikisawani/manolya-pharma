# Ticket thermique 58 mm (GOOJPRT PT-210)

Le ticket caisse n’est plus une facture A4. L’A4 imprimée sur un rouleau 58 mm sortait en **caractères microscopiques**.

## Utilisation

1. Encaisser une vente → le ticket 58 mm s’affiche (impression automatique).
2. Ou Ventes → Ticket → **Imprimer 58 mm**.
3. Dans Windows : papier **58 mm**, échelle **100 %**, décocher en-têtes/pieds de page.

Le PDF (téléchargement) est aussi au format **58 mm**, plus une facture A4.
